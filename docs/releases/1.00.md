# Tangles 1.00

First public release for the web and enhanced Sinclair QL systems.

[Play in your browser](https://hcumper.github.io/Tangles/) ·
[Download the QL player](https://github.com/HCumper/Tangles/releases/download/v1.00/tangles-1.00-ql.zip) ·
[QL installation guide](https://github.com/HCumper/Tangles/blob/v1.00/docs/QL-Install.txt)

## Play

Connect each pair of labelled endpoints using horizontal and vertical paths.
Paths cannot overlap or touch their own sides, except at consecutive squares.
Diagonal contact is allowed. Any route satisfying the rules counts.

Connections-only puzzles allow empty squares. Full-coverage puzzles require
every square to be filled. The selected pack states which rule applies.

Both editions provide mouse drawing, keyboard play, undo, reset, puzzle
navigation, a pack chooser and local JSON import. Hint completes one random
unfinished colour using the stored solution. It can clear intersecting paths;
one Undo reverses the whole hint. Progress is saved locally.

## Included puzzles

The same catalogue in both editions contains 641 puzzles in 12 packs:

- An eight-puzzle 8x8 connections-only starter pack.
- An eight-puzzle 8x8 full-coverage starter pack.
- One 3x3 quick-start puzzle.
- Six 100-puzzle 12x12 collections: Easy, Medium and Hard in each mode.
- Earlier full-coverage ramp samples: 8x8, 12x12 and 16x16.

Start with the starter or quick-start packs. Difficulty labels are provisional
and informed by solver measurements and player feedback. They are not promises
of a particular solving time or a unique solution.

## Web edition

Play at https://hcumper.github.io/Tangles/ using a modern browser with
WebAssembly and JavaScript enabled. No installation, account or desktop .NET
runtime is required. The static download can also be served by an HTTP/HTTPS
server; opening index.html directly as a local file is not supported.

Your imported files remain on your device. Progress uses browser local storage
and does not synchronise between browsers or devices. Clearing browser data
can remove progress. Imported packs must be selected again after a reload.
This version does not provide offline installation or an offline service worker.

## QL edition

Requires SMSQ/E, Pointer Environment/GD2 high colour, an 800x600 or larger
desktop, 16 MiB RAM and a writable data directory. The runtime test platform
is SMSQmulator. QPC and other SMSQ/E machines require separate compatibility
confirmation. The original 128 KiB QL is outside the supported configuration.

The download contains the compiled player, matching puzzle catalogue, boot and
restart files, Turbo Toolkit for SMSQ/E and TurboPTR. No compiler or development
tools are needed to play. An emulator, Java runtime and SMSQ/E ROM are not
included. Read readme_txt before extracting or launching.

The QL-aware ZIP preserves executable type and dataspace when extracted with
a QDOS-aware unzip. A second executable with a Qemu/SFA header allows the same
ZIP to be extracted on Windows into an SMSQmulator NFA1/SFA1 host folder.

Mouse: drag from an endpoint or an existing route; retrace to shorten it.
Keyboard: arrows move; Space/Enter starts or ends a stroke. H hints, U undoes,
C resets, P/N changes puzzle, J jumps, K chooses a pack, L imports, I shows
instructions and Q saves and quits. Restart with start, without reloading the
runtime extensions in the same interpreter session.

Large JSON packs can take time to load. QL import limits are 5 MiB of JSON,
depth 32, 32766 retained clue nodes, 128-byte IDs/labels and 64 cells per side.
Hint data for one puzzle is limited to 1 MiB. Invalid or absent optional
solutions disable hints while retaining valid clues. Labelled colours repeat
after sixteen pairs. Use zoom and keyboard panning on larger boards.

## Reliability and known limitations

The shared F# rules validate partial and completed routes. Native play, hints
and saves are checked against reference traces from those rules. Stored
solutions are checked before being used for hints. Saves remain local; undo
history is not retained across sessions. Back up your QL progress files before
upgrading and install over program/data files only, preserving saved games.

The native generator's SBASIC startup, error handling and signed-word conversion
have been corrected, including the SMSQ/E 3.13 arithmetic overflow reported as
"incomplete". The generator remains a separate development tool; these player
downloads use pre-generated packs and do not generate puzzles during play.

Report problems at https://github.com/HCumper/Tangles/issues with the edition,
version, browser/emulator, pack, puzzle number and steps to reproduce.
